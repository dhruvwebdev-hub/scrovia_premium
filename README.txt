SCROVIA PREMIUM WEBSITE
========================

Files:
- index.html
- style.css
- script.js
- assets/ (placeholder SVG images)

HOW TO USE:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server.
4. Replace the placeholder images inside assets/ with the friend's real Scrovia photos.
   Keep the same filenames, or update the image paths in index.html/style.css.

IMPORTANT:
This is an original premium redesign inspired by the existing Scrovia site structure,
not a direct copy of its code/design.
